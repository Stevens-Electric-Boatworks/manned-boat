# TidalCore

TidalCore, built on Robot Operating System 2 (ROS2) is the primary software running on the Manned Boat Controls PC. It aaggregates data from the boats sensors, communicates with motor controllers over CAN, records GPS information, and provides a data up-link via cellular to the shore system (TidalShore). It also performs data logging via ROSBag, faciltates communication with the driver dashboard, and also controls the motor controllers.

To get started, please visit the documentation at [docs.stevenseboat.org](https://docs.stevenseboat.org).
